## 확인된 현재 동작

- 로그인 성공 시 액세스 토큰과 토큰 타입 `Bearer`를 반환한다.
- JWT 필터는 `Authorization: Bearer <token>`의 토큰을 검증하고
  유효한 토큰의 사용자 ID를 인증 주체로 설정한다.
- 보안 설정은 무상태 세션을 사용하며 회원가입·로그인, 카테고리 조회,
  게시글 목록·상세 조회, 게시글 댓글 조회, 파일 조회를 공개한다.
  그 외 요청에는 인증이 필요하다.
- 게시글 작성·수정·삭제는 인증 사용자 ID를 사용하며 수정·삭제 시
  게시글 작성자 ID와 비교한다.
- 관련 테스트는 공개 조회, 보호된 요청의 누락·유효하지 않은 토큰에 대한
  401, 다른 작성자의 게시글 수정·삭제에 대한 403 등을 검증한다.
- 공개 요청에서 유효하지 않은 토큰을 항상 거부한다고 일반화하지 않는다.

근거는 `SecurityConfig`, `JwtAuthenticationFilter`,
`JwtTokenProvider`, `AuthService`, `PostController`,
`PostService`와 관련 보안·JWT·API 통합 테스트다.
