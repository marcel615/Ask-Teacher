  - JWT 필터를 `UsernamePasswordAuthenticationFilter` 앞에 등록
  - 세션 정책을 stateless로 설정
- 설정 파일 변경
  - `application.properties` 제거
  - `application.yaml` 추가
  - `jwt.secret`, `jwt.expiration` 설정 추가
- 문서 반영
  - `docs/requirements.md`
  - `docs/api-spec.md`
- ERD 변경 없음
  - Access Token은 서버 DB에 저장하지 않으므로 테이블 변경 없음
  - Refresh Token은 이번 범위에서 제외
