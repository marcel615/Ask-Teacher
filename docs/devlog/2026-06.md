## 2026-06-06 - Issue #14 게시글 삭제 API

### Issue / PR

- Issue: #14 [Feature] (post): 게시글 삭제
- Issue URL: https://github.com/marcel615/Ask-Teacher/issues/14
- PR: #19 feat(post): add soft delete API
- PR URL: https://github.com/marcel615/Ask-Teacher/pull/19
- PR 상태: OPEN

### 오늘의 작업

- Issue #14 기준으로 게시글 삭제 요구사항을 정리했다.
- 삭제 방식은 물리 삭제가 아닌 `Post.deleted = true` soft delete로 확정했다.
- 작성자 검증과 로그인 토큰 기반 인증/인가 구조 변경은 이번 Issue 범위에서 제외했다.
- 삭제 성공 응답은 기존 응답 구조와 맞춰 `200 OK + status/message`로 확정했다.
- `docs/current-task.md`, `docs/requirements.md`, `docs/api-spec.md`에 삭제 API 작업 범위를 반영했다.
- PR #19를 `docs/review-checklist.md` 기준으로 리뷰했다.
- 리뷰 코멘트를 PR에 남기고, 인코딩 깨짐 문제를 수정했다.
- `docs/api-spec.md`의 게시글 삭제 상태를 `구현 예정`에서 `구현됨`으로 수정했다.

### 변경 내용

- 게시글 삭제 API 추가
  - `DELETE /api/posts/{postId}`
  - 성공 시 `200 OK`
  - 응답 body는 `status/message`만 포함하고 `data`는 제외
- 게시글 삭제 서비스 로직 추가
  - 삭제되지 않은 게시글만 조회
  - 존재하지 않거나 이미 삭제된 게시글은 `POST_NOT_FOUND` 처리
  - 삭제 시 `deleted = true`, `updatedAt` 갱신
- `ApiResponse`에 data 없는 성공 응답 생성 메서드 추가
- 게시글 삭제 서비스 테스트 추가
- 수동 API 확인용 `.http` 파일 추가
  - `src/main/java/com/github/marcel615/askteacher/http/post/deletePost.http`
- API 명세 상태 수정
  - 게시글 삭제: `구현 예정` -> `구현됨`

### 문제 / 해결

- 해결:
  - 이번 Issue에서는 작성자 검증을 제외하고, 추후 인증/인가 리팩토링 때 보완하기로 범위를 명확히 했다.

- 해결:
  - 프로젝트 응답 구조 통일성을 우선해 `200 OK + status/message`로 확정했다.

- 문제:
  - PR 리뷰 코멘트가 PowerShell 인코딩 문제로 GitHub에서 깨져 보였다.
