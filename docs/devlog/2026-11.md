- 게시글 작성에 인증된 사용자를 사용하고 수정·삭제 시 인증 사용자와 작성자를 비교하는 현재 동작을 설명했다.
- 이미 구현된 JWT 인증과 인증 사용자 기준 작성자 검증을 향후 개선 항목에서 제거했다.

### 검증 결과 및 미확인 사항

- 보안 설정, JWT 처리, 인증 서비스, 게시글 Controller·Service와 관련 보안·JWT·API 통합 테스트를 README와 대조했다.
- Corretto 17에서 `.\gradlew.bat test --rerun-tasks`를 실행해 전체 131개 테스트가 실패·오류·건너뜀 없이 통과했다.
- `git diff --check`가 통과했다.
- README의 H2 Console 안내와 현재 보안 설정 사이의 충돌 가능성은 이번 Issue 범위 밖이며 확인하지 않았다.

### 문제 / 해결

- 최초 테스트는 `JAVA_HOME` 미설정과 PATH의 Java 부재로 시작되지 않았다. 설치된 Corretto 17을 테스트 프로세스의 `JAVA_HOME`으로 지정해 재실행했다.
- Gradle 캐시 접근 제한은 권한 승인 후 재실행해 해결했다. 기본 테스트 명령의 작업이 모두 최신 상태여서 `--rerun-tasks`로 전체 테스트를 다시 실행했다.

- Architect: Issue 분석과 설계를 수행하고 PR 변경 내용과 실제 구현·테스트를 독립적으로 대조했다. 필수 수정 사항은 발견하지 않았다.
- Builder: 승인된 README와 작업 기록을 수정하고 전체 테스트를 실행했다.
