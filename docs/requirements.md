# 요구사항 분석

## 프로젝트 목적

- 사용자가 질문 게시글을 작성하고 조회할 수 있는 Q&A 기반 서비스 API를 제공한다.
- MVP 단계에서는 회원가입, 로그인, 카테고리 조회, 게시글 작성, 게시글 목록 조회를 우선 제공한다.
- 인증이 필요한 게시글 변경 기능은 Access Token 기반 인증 사용자 정보를 사용한다.

## 사용자 유형

- 비로그인 사용자
  - 회원가입할 수 있다.
  - 로그인할 수 있다.
  - 카테고리 목록을 조회할 수 있다.
  - 게시글 목록을 조회할 수 있다.
  - 게시글 상세를 조회할 수 있다.
- 로그인 사용자
  - 게시글을 작성할 수 있다.
  - 자신의 게시글을 수정할 수 있다.
  - 자신의 게시글을 삭제할 수 있다.
  - 게시글에 좋아요를 등록할 수 있다.
  - 자신이 좋아요한 게시글의 좋아요를 취소할 수 있다.
  - 카테고리 목록, 게시글 목록, 게시글 상세를 조회할 수 있다.
- 관리자
  - MVP 범위에서는 별도 관리자 기능을 구현하지 않는다.

## MVP 기능

- [x] 회원가입
  - 이메일, 비밀번호, 닉네임을 입력해 회원가입한다.
  - 이메일과 닉네임은 중복될 수 없다.
  - 비밀번호는 8자 이상이어야 한다.
- [x] 로그인
  - 이메일과 비밀번호로 로그인한다.
  - 로그인 성공 시 Access Token과 토큰 타입을 반환한다.
  - Access Token은 인증이 필요한 API 요청에서 `Authorization: Bearer {accessToken}` 헤더로 사용한다.
- [x] 카테고리 목록 조회
  - 사용자는 게시글 작성 또는 목록 분류에 사용할 카테고리 목록을 조회할 수 있다.
  - 인증 없이 조회할 수 있다.
- [x] 게시글 작성
  - 로그인 사용자는 카테고리 ID, 제목, 내용을 입력해 게시글을 작성할 수 있다.
  - 작성자 ID는 request body로 받지 않고 Access Token의 사용자 ID를 사용한다.
  - 제목은 필수이며 100자 이하여야 한다.
  - 내용은 필수이며 5000자 이하여야 한다.
  - 새로 작성된 게시글은 `newPost = true`, `deleted = false` 상태로 생성된다.
- [x] 게시글 목록 조회
  - 사용자는 게시글 목록을 조회할 수 있다.
  - 인증 없이 조회할 수 있다.
  - 목록에는 게시글 ID, 제목, 작성자 닉네임, 카테고리명, 새 글 여부, 좋아요 수, 생성일시가 포함된다.
  - 삭제된 게시글은 목록에서 제외된다.
  - 게시글 목록은 생성일 내림차순으로 정렬해 최근 생성 게시글부터 반환한다.

## 2차 기능

- [x] 게시글 상세 조회
  - 사용자는 게시글 ID로 게시글 상세 정보를 조회할 수 있다.
  - 인증 없이 조회할 수 있다.
  - 상세 정보에는 게시글 ID, 작성자 이름, 카테고리 이름, 제목, 내용, 좋아요 수, 현재 로그인 사용자의 좋아요 여부, 생성일시가 포함된다.
  - 존재하지 않는 게시글은 조회할 수 없다.
- [x] 게시글 수정
  - 로그인 사용자는 자신의 게시글을 수정할 수 있다.
  - 수정 요청에는 카테고리 ID, 제목, 내용이 포함된다.
  - 작성자 검증은 request body의 사용자 ID가 아니라 Access Token의 사용자 ID로 수행한다.
  - 수정 가능한 값은 카테고리 ID, 제목, 내용이다.
  - 제목은 필수이며 100자 이하여야 한다.
  - 내용은 필수이며 5000자 이하여야 한다.
  - 존재하지 않는 게시글은 수정할 수 없다.
  - 존재하지 않는 카테고리로 수정할 수 없다.
  - 게시글 작성자가 아닌 사용자는 수정할 수 없다.
  - 수정 시 게시글의 `updatedAt`을 갱신한다.
- [x] 게시글 삭제
  - 로그인 사용자는 자신의 게시글을 삭제할 수 있다.
  - 작성자 검증은 Access Token의 사용자 ID로 수행한다.
  - 삭제는 DB row를 물리 삭제하지 않고 게시글의 `deleted` 값을 `true`로 변경한다.
  - 존재하지 않는 게시글은 삭제할 수 없다.
  - 이미 삭제된 게시글은 존재하지 않는 게시글과 동일하게 처리한다.
  - 게시글 작성자가 아닌 사용자는 삭제할 수 없다.
  - 삭제 시 게시글의 `updatedAt`을 갱신한다.
- [ ] 게시글 좋아요
  - 로그인 사용자는 게시글에 좋아요를 등록할 수 있다.
  - 로그인 사용자는 자신이 좋아요한 게시글의 좋아요를 취소할 수 있다.
  - 하나의 사용자는 같은 게시글에 좋아요를 1개만 등록할 수 있다.
  - 존재하지 않거나 삭제된 게시글에는 좋아요를 등록하거나 취소할 수 없다.
  - 이미 좋아요한 게시글에 다시 좋아요 등록을 요청하면 실패한다.
  - 좋아요하지 않은 게시글에 좋아요 취소를 요청하면 실패한다.
  - 게시글 목록 조회 응답에는 좋아요 수가 포함된다.
  - 게시글 상세 조회 응답에는 좋아요 수와 현재 로그인 사용자의 좋아요 여부가 포함된다.

## 제외 범위

- Refresh Token, 로그아웃, 토큰 재발급은 현재 범위에서 다루지 않는다.
- MVP에서는 관리자 전용 API를 다루지 않는다.
- 검색, 페이징, 정렬 파라미터는 현재 범위에서 다루지 않는다.
- 댓글 CRUD, 파일 업로드, 고도화된 권한 처리는 현재 범위에서 다루지 않는다.
