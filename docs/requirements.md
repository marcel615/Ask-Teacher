# 요구사항 분석

## 프로젝트 목적

- 사용자가 질문 게시글을 작성하고 조회할 수 있는 Q&A 기반 서비스 API를 제공한다.
- MVP 단계에서는 회원가입/로그인, 카테고리 조회, 게시글 작성, 게시글 목록 조회를 우선 제공한다.

## 사용자 유형

- 비로그인 사용자:
  - 회원가입할 수 있다.
  - 로그인할 수 있다.
  - 카테고리 목록을 조회할 수 있다.
  - 게시글 목록을 조회할 수 있다.
- 일반 사용자:
  - 게시글을 작성할 수 있다.
  - 게시글 목록을 조회할 수 있다.
- 관리자:
  - MVP 범위에서는 별도 관리자 기능을 구현하지 않는다.

## MVP 기능

- [x] 회원가입
  - 이메일, 비밀번호, 닉네임을 입력해 회원가입한다.
  - 이메일과 닉네임은 중복될 수 없다.
  - 비밀번호는 8자 이상이어야 한다.
- [x] 로그인
  - 이메일과 비밀번호로 로그인한다.
  - 로그인 성공 시 사용자 식별 정보와 닉네임을 반환한다.
- [x] 카테고리 목록 조회
  - 사용자는 게시글 작성 또는 목록 분류에 사용할 카테고리 목록을 조회할 수 있다.
- [x] 게시글 작성
  - 사용자는 작성자 ID, 카테고리 ID, 제목, 내용을 입력해 게시글을 작성할 수 있다.
  - 제목은 필수이며 100자 이하이다.
  - 내용은 필수이며 5000자 이하이다.
  - 새로 작성된 게시글은 `newPost = true`, `deleted = false` 상태로 생성된다.
- [ ] 게시글 목록 조회
  - 사용자는 게시글 목록을 조회할 수 있다.
  - 목록에는 게시글 ID, 제목, 작성자 닉네임, 새 글 여부, 생성일이 포함된다.
  - 삭제된 게시글은 목록에서 제외한다.

## 2차 기능

- [ ] 게시글 상세 조회
- [ ] 게시글 수정
  - 사용자는 게시글 ID로 기존 게시글을 수정할 수 있다.
  - 수정 요청에는 사용자 ID, 카테고리 ID, 제목, 내용을 포함한다.
  - 요청 사용자 ID가 게시글 작성자 ID와 일치할 때만 수정할 수 있다.
  - 수정 가능한 값은 카테고리 ID, 제목, 내용이다.
  - 제목은 필수이며 100자 이하이다.
  - 내용은 필수이며 5000자 이하이다.
  - 존재하지 않는 게시글은 수정할 수 없다.
  - 존재하지 않는 사용자는 수정할 수 없다.
  - 존재하지 않는 카테고리로 수정할 수 없다.
  - 수정 시 게시글의 updatedAt이 갱신된다.

## 제외 범위

- MVP에서는 JWT 발급/검증 등 인증 토큰 기반 권한 처리를 다루지 않는다.
- MVP에서는 관리자 전용 API를 다루지 않는다.
- Issue #5에서는 게시글 목록 조회만 다루며, 검색/페이징/정렬 조건은 포함하지 않는다.
