# 기능 아이디어

기능 후보의 관리 기준은 GitHub Projects의 `Ask Teacher` Draft Issue다. 이 문서는 이전 형식의 참고 기록이며 신규 후보나 승인 상태를 이곳에 기록하지 않는다. 기존 형식의 실제 후보가 발견되면 Projects와 대조해 누락·중복 여부를 확인한다.

## 이전 후보 관리 형식 (참고)

아래는 이전에 사용하던 형식이다. 구현 기준은 `requirements.md`, 실제 작업 관리는 GitHub Issue에서 담당한다.

- 사용자와 AI가 제안할 수 있으며, 승인 체크는 사용자만 한다. 사용자와 AI의 제안 모두 체크되어야 Issue화 후보로 검토한다.
- 승인 체크는 Issue화 후보로 검토할 수 있다는 뜻이며 상세 요구사항이나 구현 승인이 아니다.
- Issue를 생성하거나 기존 Issue와 연결하면 번호와 링크를 기록한다. 연결된 항목은 Issue가 닫혔더라도 자동으로 다시 생성하지 않는다.
- Main은 Issue화 전 기존 Issue와 중복을 확인한다. 미결정 사항은 추측하지 않고 기록한다.

## 후보 작성 형식

아래 항목을 복사해 새 후보를 추가한다. 이 형식은 실제 후보가 아니다.

```markdown
## 후보 제목

- 후보 ID: IDEA-고유값
- 제안: 사용자 또는 AI
- 배경:
- 제안 내용:
- 확인 필요:
- [ ] 사용자 승인
- 연결 Issue: 없음
```

후보 ID는 후보별로 고유하고 생성 후 변경하지 않는다. Issue를 새로 만들 때 동일 ID를 Issue 본문에 남겨 중단 후 중복 여부를 확인한다.
