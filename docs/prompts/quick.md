# Quick Prompts

상세 절차와 승인 경계는 `.agents/skills/issue-driven-dev/SKILL.md`와 `AGENTS.md`를 따른다.
아래 문구는 예시이며 같은 뜻의 자연스러운 지시도 사용할 수 있다.
승인은 직전에 제시된 내용과 명시된 행동에만 적용된다.

## Issue와 설계

- 시작: `Issue #번호 작업 시작해.`
- Issue 초안 승인: `Issue 초안을 승인하고 GitHub에 등록해.`
- Issue 수정 승인: `Issue 수정안을 승인하고 반영해.`
- 설계 승인: `설계와 문서 수정안을 승인하고 반영해.`

## 구현과 PR

- 계획 요청: `구현과 브랜치 계획을 제안해.`
- 구현 승인: `브랜치 생성과 구현 계획을 승인해.`
- PR 준비: `커밋 메시지와 PR 초안을 제안해.`
- PR 생성 승인: `커밋, push, PR 생성을 승인해.`

## 리뷰와 기록

- 리뷰 요청: `현재 PR을 리뷰해.`
- 리뷰 등록 승인: `리뷰 등록을 승인해.`
- 수정안 요청: `리뷰 반영안을 제안해.`
- 수정 승인: `제안한 리뷰 수정을 승인해.`
- 수정 반영 승인: `리뷰 수정의 commit과 push를 승인해.`
- 기록 요청: `devlog 초안을 작성해.`
- 기록 반영 승인: `devlog 반영과 commit, push를 승인해.`

## 종료와 중단

- 정리: `PR 머지 후 develop 최신화와 브랜치 정리를 진행해.`
- 중단: `작업을 멈추고 현재 상태와 남은 작업을 알려줘.`
